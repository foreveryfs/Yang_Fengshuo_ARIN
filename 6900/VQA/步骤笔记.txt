由于你的项目使用的是 Python 3.10，而 MMF 是基于 Python 3.7/3.8 时代编写的。Python 3.10 彻底移除了 collections.Mapping 等老旧的快捷别名（全部强制移到了 collections.abc 下）。

当你接下来运行 test_bert.py 时，百分之百会触发以下致命报错：

AttributeError: module 'collections' has no attribute 'Mapping'

💡 提前避坑解决方案：
请打开你的 test_bert.py 文件，在代码的最顶端（第 1 行，必须在所有其他 import 之前），死死地贴上这段动态兼容补丁：

Python
# ================= Python 3.10 强行兼容 MMF 远古代码补丁 =================
import collections
import collections.abc
collections.Mapping = collections.abc.Mapping
collections.MutableMapping = collections.abc.MutableMapping
collections.Sequence = collections.abc.Sequence
collections.MutableSequence = collections.abc.MutableSequence
# =========================================================================

import yaml
import torch
import requests
# ... 后面保持你原有的代码不动
这段补丁会在程序启动的一瞬间建立映射，欺骗 MMF 的底层源码，让它在现代的 Python 3.10 上也能完美跑通。做完这些后，你就可以放心去运行你的 test_bert.py 脚本了。

2.离线资源---------------------------------------------------------------------------
1. 目标检测与特征提取资源（服务于 image_to_feature.py）
这个文件是用 Detectron2 来提取图像的 BUTD（Bottom-Up Top-Down）特征，它需要：

词表文件：objects_vocab.txt 和 attributes_vocab.txt（Visual Genome 数据集的物体和属性标签词表，代码里通过 os.path.join(data_path, ...) 读取）。

检测器模型配置与权重：

经典的 Bottom-Up 目标检测器配置文件（.yaml）。

预训练好的 Faster R-CNN 权重文件（.pth 或 .bin）。

2. VQA 官方数据集与 COCO 图库（服务于 answer_to_question.py / image_cut.py 等）
做数据变异（裁剪、插入、删除）和评测需要基础图库：

文本标注：VQA v2 或 Abstract VQA 的官方问答 JSON 文件（例如 OpenEnded_abstract_v002_val2015_questions.json）。

图像数据：COCO 2014 或 2017 的图片集（用于 cv2.imread 读取并进行图像操作）。

COCO API 实例：pycocotools 需要的 instances_train2014.json 等标准的 COCO 目标检测标注文件（image_insert.py 中有调用）。

3. 多模态预训练模型权重（服务于 test_bert.py）
VisualBERT / ViLBERT 权重：MMF 框架虽然能自动下载，但在超算计算节点通常无法连接外网。你必须提前下载好 visual_bert 的预训练权重（通常是 .pth 或 .bin），并将其放置在 MMF 的缓存目录（通常在 ~/.cache/torch/mmf/）或指定路径下。

📥 一、 必须预下载的模型权重列表
1. 🟢 边缘精细抠图模型（真实图 / 卡通图通用）
模型名称: SAM (Segment Anything Model)

Hugging Face ID: facebook/sam-vit-base

下载作用: 你的需求是“已知坐标（Bounding Box）”。但如果直接用方框去增删，画面会留下死板的方形切痕。SAM 的作用是把你的 [xmin, ymin, xmax, ymax] 矩形框输入进去，自动吸附并输出像素级贴合的黑色/白色 Mask（掩膜）图像。

2. 🔵 真实图像编辑底模（负责真实照片的增/删）
模型名称: Stable Diffusion v1.5 Inpainting

Hugging Face ID: runwayml/stable-diffusion-inpainting

下载作用: 专门针对局部重绘训练的 9 通道标准大模型。

删除时：用它涂抹运动员，输入提示词 "clean background, running track" 就能完美抹除人并缝合跑道。

添加时：在空白区画个框，输入提示词 "a sports water bottle, photorealistic" 就能无中生有出一个带写实阴影的水壶。

3. 🟡 抽象/卡通编辑底模（负责 2D/动漫卡通图的增/删）
模型名称: Anime Inpainting (动漫局部重绘特调版)

Hugging Face ID: cyberdelia/AnimeInpainting

下载作用: 如果用上面的写实模型去改卡通图，画面会彻底崩坏（比如在平涂卡通客厅里塞入一个高清毛发毕现的猫）。这个模型能完美识别线稿和平涂（Flat Shading），配合提示词（如 "abstract cartoon style, a cute cat"），可以保证添加的物体自带黑色描边，完美融入 Abstract Scenes 数据集。
